## Lazyweb 审查参考

已通过 MCP 直接验证：

- `lazyweb_health`：返回 healthy，Supabase/OpenAI/Voyage/Cohere 均 ok。
- `lazyweb_search {"query":"pricing page","limit":3}`：返回桌面 pricing 与移动订阅页参考，包括 Ramp、Cryo Mix、Replit、OnePay、Universe 等。
- `lazyweb_search {"query":"mobile admin task review list approval evidence workflow","platform":"mobile"}`：返回 Asana、Trello 等移动任务详情参考，用于校准审核/证据/状态动作的移动端信息层级。
- `lazyweb_search {"query":"mobile CRM task list partner dashboard bottom navigation business app","platform":"mobile"}`：返回 Asana、Any.do 等移动任务列表参考，用于校准移动端“状态、日期、负责人、主操作”优先级。

对本项目 UI 的采用原则：

- 移动端付费/订阅页的计划选择模式启发了红包任务、审核任务的单列信息层级：价格/状态/CTA 保持首屏可见。
- 桌面 pricing 的 tier/card 结构只作为信息分组参考，不照搬三卡营销布局；本项目是运营后台，优先低噪声、可扫描、可重复操作。
- 审核流参考 finance/developer tool 类产品的明确状态标签、主次按钮和证据列表，避免只有 toast 的隐形状态。
- 移动任务详情参考 Asana/Trello 的“状态 + 负责人/日期 + 附件/证据 + 更新动作”结构，用于红包驳回后的重提路径和后台审核详情。

## 移动端优先验收清单

- 注册：375px 宽度下三步表单、身份证校验说明、资源标签多选无横向滚动。
- 注册登录：注册提交后移动端提示进入后台审核；审核前账号不可登录；审核通过后生成系统账号并可进入合伙人端。
- AI 线索：搜索条件、提示词、资源标签、线索卡片、详情/策略/申请操作单列可用。
- CRM：项目列表、对接人填写、线上接洽确认、排他状态在 Sheet 中完成，不依赖桌面表格。
- 客户绑定：冲突提示、补对接人、线上接洽、释放绑定均可在移动弹窗中完成。
- CRM/绑定同步：在任一入口补对接人、确认线上接洽或释放绑定后，另一入口状态应同步变化。
- 释放归属：客户绑定释放后，CRM 项目、线索池和后台线索归属都应回到可重新分配状态。
- 红包任务：领取、上传凭证、查看审核意见均可在移动卡片与弹窗中完成。
- 红包结算：红包凭证后台审核通过后，合伙人端红包变为已发放，结算页新增已结算记录。
- 红包驳回：已驳回任务可直接重新上传凭证，重提后回到待审核。
- 后台审核：线索管理、商务跟进、激励审核均保留移动卡片视图。
- 后台总览：进入后台后首屏可看到待处理队列，并能跳转到对应处理页面。
- 后台总览二期队列：绑定到期、培训草稿、AIGC模板缺口、待结算佣金均有明确入口。
- 后台线索：可查看线索详情、分配合伙人、识别绑定冲突、释放归属。
- 后台客户绑定：可搜索客户/合伙人，筛选生命周期阶段，处理延期、重分配和释放，且释放同步线索池/CRM/后台线索。
- 后台商务：可从统一表查看详情、标记签单、释放归属。
- 后台合伙人：移动端可查看待审核申请，完成通过/驳回；已通过合伙人可在详情中编辑、停用、删除。
- 后台培训：移动端可新增、编辑、发布、下架培训内容；合伙人端只看到已发布内容。
- 后台 AIGC：移动端可维护模板和审查历史；合伙人端生成内容读取启用模板。
- 后台分佣：移动端可处理待结算、冻结、发放和人工调整；金额使用 k/w 简写防止截断。
- 后台线索：管理员改派后应能在合伙人端 CRM 与客户绑定中看到同步结果。
- 产品货架：移动端只展示一二期核心服务，不出现三期项目方案、供应链扩展、虚拟电厂或厂家售前支持入口。
- 产品货架管理：后台可新增、编辑、上下线、删除一二期服务配置，刷新后仍保留。

## 仍需后端接入的边界

当前实现仍是前端原型，以下能力需要后端/API 后才能达到生产要求：

- 身份证实名核验、正式账号注册落库与密码安全策略。
- 公开信息抓取、政策库、行业知识库和真实 AI 推理。
- 线索归属、绑定冲突、排他释放、审核日志的服务端一致性。
- 图片上传、Logo 文件存储、红包付款、分佣结算和权限审计。
- Lazyweb plugin 热加载后的正式工具面板验证；当前已完成 HTTP MCP 级验证。
