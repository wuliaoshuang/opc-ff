# 钉钉与微信小程序入口接入说明

## 钉钉消息入口

用途：从钉钉工作通知、消息卡片或企业工作台进入 OPC，并完成免登。

申请步骤：

1. 企业管理员登录钉钉开放平台：https://open.dingtalk.com/
2. 创建企业内部应用，建议选择 H5 微应用/企业应用。
3. 配置应用首页地址，例如 `https://your-domain.com/#/partner/dashboard`。
4. 配置免登回调地址，例如 `https://your-domain.com/auth/dingtalk/callback`。
5. 申请通讯录身份读取相关权限，用免登 code 换取用户身份。
6. 配置工作通知或消息卡片跳转地址，带上业务参数，例如项目 id、任务 id。
7. 后端用钉钉用户标识匹配 OPC 账号，匹配成功后签发系统登录态。

需要交付给开发的参数：

- 企业 `CorpId`
- 应用 `AppKey` / `Client ID`
- 应用 `AppSecret` / `Client Secret`
- 免登回调地址
- 消息卡片跳转地址规则

验收口径：

- 从钉钉消息卡片点击进入 OPC。
- 首次进入能绑定手机号或系统账号。
- 再次进入能自动识别身份，进入对应合伙人或管理员页面。
- 项目/任务消息可以跳转到具体业务页面。

## 微信小程序入口

用途：通过微信小程序提供移动端轻量访问入口，承载首页看板、项目跟进、红包任务等流程。

申请步骤：

1. 主体管理员登录微信公众平台：https://mp.weixin.qq.com/
2. 注册小程序并完成主体认证。
3. 在开发管理中获取 `AppID`，生成 `AppSecret`。
4. 配置服务器域名，域名必须 HTTPS 且已备案。
5. 如使用 web-view 承载 H5 页面，还需要配置业务域名。
6. 小程序端调用 `wx.login` 获取 code。
7. 后端通过 code2Session 换取 `openid` / `session_key`。
8. 将 `openid` / `unionid` 与 OPC 账号绑定，签发系统登录态。

需要交付给开发的参数：

- 小程序 `AppID`
- 小程序 `AppSecret`
- request 合法域名
- 业务域名 / web-view 域名
- 登录 code2Session 接口地址

验收口径：

- 从微信小程序进入 OPC。
- 首次进入提示绑定手机号或系统账号。
- 再次进入自动识别身份。
- 能进入移动端首页看板、目标项目、个人项目和红包任务。

## 当前原型状态

- 登录页已提供「钉钉消息入口」和「小程序入口」接入面板。
- 面板内包含申请入口、回调地址、所需参数、实施步骤和验收口径。
- 当前前端原型不包含真实第三方免登，因为真实接入需要企业主体、管理员授权、正式域名和后端密钥配置。
